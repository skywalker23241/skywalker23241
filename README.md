## `05 // 我在意的产品原则`

| 原则 | 实践 |
|---|---|
| **快** | 控制依赖、减少无意义 JavaScript、优先真实加载体验 |
| **好用** | 响应式、清晰的信息层级、减少操作成本 |
| **可发现** | 从语义结构、内容架构和技术 SEO 开始设计 |
| **可维护** | 简单架构、明确数据边界、能长期迭代而不是一次性 Demo |
| **用户掌控数据** | 能本地存储就不强制上云，能导出就不锁定 |
